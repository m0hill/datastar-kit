Datastar Kit SDK Audit

SDK Interface Depth Improvements

The examples exposed caller friction. The SDK absorbed the repeated behavior into smaller Interfaces while keeping Datastar and Web Standards as the primary Seams.

Signal Refs Initialize Signal Attributes

Strong

Files touched

src/ds/attributes.ts, signal policy tests, misc attribute tests, official examples, signals docs, API reference.

Problem

Standalone signal initialization forced callers to leak signal.name.

Solution

ds.dataSignal(...) and ds.dataComputed(...) now accept signal refs directly.

Wins

Leverage: a signal ref carries the name into initialization. Locality: keyed casing and fallback behavior stay in attributes.ts. 

flowchart TB
  subgraph Before
    A["Caller"] --> B["Signal.name"]
    B --> C["dataSignal(name, value)"]
  end
  subgraph After
    D["Caller"] --> E["dataSignal(signal, value)"]
    E --> F["Signal path resolved inside Module"]
  end

Signal Mutation Helpers

Strong

Files touched

src/ds/actions.ts, src/ds/index.ts, expression tests, official examples, modal example, actions docs, signals docs, API reference.

Problem

Callers repeated inline JavaScript for assignment, sequencing, and guarded requests.

Solution

Added ds.set, ds.sequence, and ds.when.

Wins

Leverage: common Datastar expression behavior is one small Interface. Locality: assignment and statement serialization bugs concentrate in one Module.

Before
ds.expr`${signal} = false` ds.expr`${post}; ${signal} = false`
After
ds.set(signal, false) ds.sequence(post, ds.set(signal, false))

Stream Wrapper Removed

Worth exploring

Files touched

src/reply.ts, platform response tests, export boundary tests, changelog.

Problem

reply.stream() accepted an unused { content } wrapper that added an Interface shape without Depth.

Solution

Removed SseChunk and kept strings, bytes, iterables, async iterables, and Web streams.

Wins

Leverage remains the same for real callers. Locality improves because stream normalization has fewer paths. 

flowchart LR
  subgraph Before
    B1["string"] --> S["reply.stream"]
    B2["Uint8Array"] --> S
    B3["{ content }"] --> S
    B4["ReadableStream"] --> S
  end
  subgraph After
    A1["string"] --> T["reply.stream"]
    A2["Uint8Array"] --> T
    A3["ReadableStream"] --> T
  end

Query URLs Preserve Fragments

Strong

Files touched

src/ds/actions.ts, URL tests, changelog.

Problem

queryUrl("/search#results", params) placed generated params inside the hash.

Solution

Split the hash before query assembly, then reattach it after generated params.

Wins

Leverage: callers can pass normal path strings. Locality: separator and fragment rules live in queryUrl.

Script Event Attribute Validation

Strong

Files touched

src/html.ts, src/sse.ts, SSE tests, changelog.

Problem

Script SSE events escaped attribute values but did not validate attribute names.

Solution

Reused the HTML Module's attribute-name assertion in executeScript.

Wins

Leverage: every generated HTML path shares one invariant. Locality: future name fixes land in the HTML Module. 

flowchart TB
  A["HtmlNameError invariant"] --> B["renderToString props"]
  A --> C["executeScript attributes"]
  B --> D["Safe HTML output"]
  C --> D

Redundant Signal Type Args Removed

Speculative

Files touched

src/ds/actions.ts, src/ds/attributes.ts.

Problem

Type-aware lint reported redundant default Signal type arguments.

Solution

Removed default type arguments from internal annotations.

Wins

Leverage is unchanged. Locality improves slightly because type annotations are quieter and lint-clean.

Before
Signal<T, string>
After
Signal<T>

Top Changes

  • Signal mutation helpers: highest Leverage. They remove repeated inline JavaScript while keeping the Interface JavaScript-shaped.
  • Signal refs accepted by attribute helpers: best Interface cleanup. The signal Module now carries its own path into initialization.
  • Script attribute validation: strongest Locality fix. One HTML name invariant now covers renderer output and SSE script events.
  • Stream wrapper removal: clearest deletion-test pass. Removing the wrapper erased complexity without pushing work to callers.
